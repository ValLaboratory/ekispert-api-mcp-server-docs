## 駅情報の取得

### 例1: 駅名から駅情報を取得

**:speech_balloon: プロンプトでの指示**:
```
東京駅の情報を教えて
```

**期待される動作**:
- 「駅すぱあと API」が駅名「東京」で検索
- 東京駅の駅コードなどの情報が返される

**サンプルレスポンス（抜粋）**:

```json
{
  "ResultSet": {
    "Point": [
      {
        "Station": {
          "code": "22828",
          "Name": "東京",
          "Type": "train",
          "Yomi": "とうきょう"
        },
        "Prefecture": { "code": "13", "Name": "東京都" }
      }
    ]
  }
}
```
**返される情報の例**:
- 駅名: 東京
- 駅コード: 22828
- 交通種別: 鉄道
- 都道府県: 東京都

**ポイント**:
- `simplify` を省略した場合はデフォルトの `"true"` が適用され、座標情報（`GeoPoint`）は返りません。座標情報が必要な場合は `simplify="false"` を指定してください

### 例2: 駅コードから駅情報を取得

**:speech_balloon: プロンプトでの指示**:
```
駅コード 22741 の駅の情報を教えて
```

**期待される動作**:
- 「駅すぱあと API」が駅コード 22741（新宿駅）の情報を検索
- 新宿駅の詳細情報が返される

### 例3: 特定の交通種別の駅情報を取得

**:speech_balloon: プロンプトでの指示**:
```
高円寺駅のバス停の情報を教えて（路線バスだけ）
```

**期待される動作**:
- `type: "bus.local"` を指定して高円寺駅のバス停情報を取得
- バス停一覧が返される

### 例4: 駅の座標情報を取得

**:speech_balloon: プロンプトでの指示**:
```
東京駅の座標を教えて
```

**期待される動作**:
- 「駅すぱあと API」が駅名「東京」で検索
- 東京駅の駅コード、座標などの情報が返される

**サンプルレスポンス（抜粋）**:

```json
{
  "ResultSet": {
    "Point": [
      {
        "Station": {
          "code": "22828",
          "Name": "東京",
          "Type": "train",
          "Yomi": "とうきょう"
        },
        "Prefecture": { "code": "13", "Name": "東京都" },
        "GeoPoint": {
          "longi": "139.46.2.4",
          "lati": "35.40.52.71",
          "longi_d": "139.767234",
          "lati_d": "35.68131",
          "gcs": "wgs84"
        }
      }
    ]
  }
}
```
**返される情報の例**:
- 駅名: 東京
- 駅コード: 22828
- 座標: 北緯 35.40.52.71、東経 139.46.2.4
- 都道府県: 東京都

**ポイント**:
- 座標情報を取得するには `simplify="false"` の指定が必要です
- 測地系は `gcs` で指定します。省略時は世界測地系（`wgs84`）の座標が返ります

## 基本的な経路探索

### 例5: シンプルな2地点間の経路探索

**:speech_balloon: プロンプトでの指示**:
```
東京駅から新宿駅への経路を教えて
```

**期待される動作**:
- 出発駅: 東京、目的駅: 新宿 で経路探索
- 駅すぱあと探索順（デフォルト）で複数の経路が返される

**返される情報の例**:
- 経路1: ＪＲ中央線快速（直通）
  - 所要時間: 約14分
  - 料金: 260円
  - 乗換回数: 0回
- 経路2: ＪＲ山手線内回り＋ＪＲ総武線
  - 所要時間: 約22分
  - 料金: 260円
  - 乗換回数: 1回

**サンプルレスポンス（抜粋）**:

```json
{
  "ResultSet": {
    "Course": [
      {
        "Price": [{ "Oneway": "260" }],
        "Route": {
          "timeOnBoard": "14",
          "transferCount": "0",
          "Line": [
            {
              "timeOnBoard": "14",
              "Name": "ＪＲ中央線快速"
            }
          ]
        }
      }
    ]
  }
}
```

### 例6: 料金が最も安い経路を探索

**:speech_balloon: プロンプトでの指示**:
```
東京駅から新宿駅への最も安い経路を教えて
```

**期待される動作**:
- `sort: "price"` を指定して経路探索

**:speech_balloon: プロンプトでの指示**:

**返される情報の例**:

## 詳細な条件を指定した経路探索

### 例8: 定期券の料金を確認

**:speech_balloon: プロンプトでの指示**:
```
東京から新宿までの3ヶ月定期券の料金を教えて
```

**期待される動作**:
- `sort: "teiki3"` を指定して経路探索
- 3ヶ月定期券の料金情報が含まれた経路が返される

**返される情報の例**:
- 経路: ＪＲ中央線快速（東京→新宿）
- 1ヶ月定期: 8,820円
- 3ヶ月定期: 25,160円
- 6ヶ月定期: 47,660円

**注意**: 現在は、定期券の料金情報の取得のみ可能です。定期控除計算は今後のバージョンで対応予定です。

### 例9: 複数の回答を取得

**:speech_balloon: プロンプトでの指示**:
```
東京から大阪まで、10通りの経路を教えて
```

**期待される動作**:
- `answerCount: 10` を指定
- 最大10通りの経路が返される

**注意**:
- 実際の経路数は探索結果に依存するため、10通り未満になることもあります
- より多くの結果を得たい場合は `searchCount` を増やします

### 例10: 駅を確定させてから経路探索

**:speech_balloon: プロンプトでの指示**:
```
高円寺から野方二丁目までの関東バスの経路を教えて
```

**期待される動作**:
- `name: 高円寺` および `type: "bus"` を指定して駅情報取得
- `name: 野方二丁目` および `type: "bus"` を指定して駅情報取得
- 取得した駅情報を使用した `viaList: 高円寺駅北口／関東バス:野方二丁目／関東バス` を指定して経路探索
- 関東バス路線を含む経路が返される

**返される情報の例**:
- 経路: 高円寺駅北口／関東バス→(関東バス・高60系統)→野方二丁目／関東バス
- 所要時間: 5分
- 運賃: 230円
- 乗換回数: 0回

### 例11: 詳細な探索条件を指定（新幹線、飛行機利用なし、ICカード優先）

**:speech_balloon: プロンプトでの指示**:
```
新幹線や飛行機を使わずに、ICカード優先で東京から大阪へ行きたい
```

**期待される動作**:
- `shinkansen: "never"`, `plane: "never"`, `ticketSystemType: "ic"`, `preferredTicketOrder: "ic"`を指定して [探索条件生成](https://docs.ekispert.com/v1/api/toolbox/course/condition.html) を行う
- `viaList: "東京:大阪"` 、および、生成された探索条件 `conditionDetail: "T11212332323191:F332112112200010:A23121141:"` を指定して経路探索
- 新幹線を利用しない経路が返される

**返される情報の例**:
- 経路: 東京→(ＪＲ山手線外回り)→渋谷→(徒歩)→渋谷マークシティ(高速・連絡バス)→高速バス(新宿・渋谷－京都・枚方)→山科駅前(高速・連絡バス)→(徒歩)→山科→(ＪＲ東海道・山陽本線新快速)→大阪
- 所要時間: 7時間54分
- 運賃: 7,848円(IC)
- 乗換回数: 2回

### 例12: 出発時刻を指定した経路探索（ダイヤ探索）

**自然言語での指示**:
```
東京から新宿まで、明日の朝9時に出発する経路を教えて
```

**期待される動作**:
- `date: {{YYYYMMDD 形式の翌日の日付(数値)}}`, `time: "0900"`, `searchType: "departure"` を指定して経路探索
- 指定した出発時刻に基づく実際の列車の時刻表を使用した経路が返される

**返される情報の例**:
- 経路: 東京 9:00発→(ＪＲ中央線快速)→新宿 9:14着
- 所要時間: 14分
- 料金: 210円
- 乗換回数: 0回

**ポイント**:
- `searchType: "departure"` を指定することで、発時刻探索（早く到着し遅く出発する経路）が優先されます
- 時刻表に基づいた正確な出発時刻・到着時刻が取得できます

### 例13: 到着時刻を指定した経路探索（ダイヤ探索）

**自然言語での指示**:
```
東京から新宿まで、18時までに到着する経路を教えて
```

**期待される動作**:
- `time: "1800"`, `searchType: "arrival"` を指定して経路探索
- 18時までに到着する経路のうち、遅く出発し早く到着する経路が優先される

**返される情報の例**:
- 経路: 東京 17:46発→(ＪＲ中央線快速)→新宿 18:00着
- 所要時間: 14分
- 料金: 210円
- 乗換回数: 0回

**ポイント**:
- `searchType: "arrival"` を指定することで、着時刻探索（遅く出発し早く到着する経路）が優先されます
- できるだけ遅い時間に出発できる経路を検索できます

### 例14: 終電・始発の経路探索（ダイヤ探索）

**自然言語での指示（終電）**:
```
東京から大阪までの終電を教えて
```

**期待される動作**:
- `searchType: "lastTrain"` を指定して経路探索
- 指定日の最終ダイヤの経路が返される

**自然言語での指示（始発）**:
```
東京から大阪までの始発を教えて
```

**期待される動作**:
- `searchType: "firstTrain"` を指定して経路探索
- 指定日の始発ダイヤの経路が返される

**ポイント**:
- `lastTrain` と `firstTrain` では `time` パラメータは指定できません
- 終電・始発は日付によって変わる可能性があるため、`date` パラメータで日付を指定することを推奨します

### 例15: 複数の並び順で経路を比較（ダイヤ探索）

**自然言語での指示**:
```
横浜から池袋まで、18時までに到着する経路で、早い・安い経路をそれぞれ教えて
```

**期待される動作**:
- `time: "1800"`, `searchType: "arrival"`, `sort: "time"` を指定して時間順で経路探索
- `time: "1800"`, `searchType: "arrival"`, `sort: "price"` を指定して料金順で経路探索
- 両方の結果を比較して最適な経路を選択

**返される情報の例（早さ重視）**:
- 経路: 横浜 17:19発→(ＪＲ湘南新宿ライン快速)→池袋 17:57着
- 所要時間: 38分
- 料金: 660円
- 乗換回数: 0回

**返される情報の例（安さ重視）**:
- 経路: 横浜 17:07発→(東急東横線通勤特急)→渋谷→(ＪＲ湘南新宿ライン快速)→池袋 17:57着
- 所要時間: 50分
- 料金: 490円
- 乗換回数: 1回

**ポイント**:
- 同じ到着時刻制限でも、並び順によって異なる経路が最適解として提示される
- 時間と料金のトレードオフを比較検討できる

## 範囲探索

### 例16: 通勤圏内の駅を探す

**:speech_balloon: プロンプトでの指示**:
```
新宿駅から電車で30分以内で行ける駅を教えて
```

**期待される動作**:
- `baseList: ["新宿"]`、`upperMinutes: [30]` で範囲探索
- 30分以内に到達できる駅の一覧が、所要時間・乗換回数とともに返される

**サンプルレスポンス（抜粋）**:

```json
{
  "ResultSet": {
    "Point": [
      {
        "Station": { "code": "29342", "Name": "新宿(東京メトロ)", "Type": "train" },
        "Prefecture": { "code": "13", "Name": "東京都" },
        "Cost": { "baseIndex": "1", "Minute": "2", "TransferCount": "0" }
      }
    ]
  }
}
```

**返される情報の例**:
- 駅名: 新宿(東京メトロ)
- 駅コード: 29342
- 所要時間: 2分
- 乗換回数: 0回
- 都道府県: 東京都

### 例17: 待ち合わせ場所を探す

**:speech_balloon: プロンプトでの指示**:
```
新宿と横浜、それぞれから30分以内で行ける駅の中で、集合しやすい場所を教えて
```

**期待される動作**:
- `baseList: ["新宿", "横浜"]`、`upperMinutes: [30, 30]` で範囲探索
- 両方の起点駅から30分以内で到達できる共通の駅が返される
- 各駅には起点駅ごとの所要時間が `Cost` の配列として含まれる（`baseIndex` が `baseList` の何番目かを表す）

**サンプルレスポンス（抜粋）**:

```json
{
  "ResultSet": {
    "Point": [
      {
        "Station": { "code": "22855", "Name": "中目黒", "Type": "train" },
        "Prefecture": { "code": "13", "Name": "東京都" },
        "Cost": [
          { "baseIndex": "1", "Minute": "19", "TransferCount": "1" },
          { "baseIndex": "2", "Minute": "30", "TransferCount": "0" }
        ]
      }
    ]
  }
}
```

**返される情報の例**:
- 駅名: 中目黒
- 新宿からの所要時間: 19分（乗換1回）
- 横浜からの所要時間: 30分（乗換なし）

**ポイント**:
- 起点駅を増やすほど、すべての条件を満たす共通の駅は少なくなります。結果が0件になる場合は、所要時間の上限を広げてください

### 例18: 起点ごとに異なる条件を指定する

**:speech_balloon: プロンプトでの指示**:
```
Aさんは新宿から乗り換えなしで30分以内、Bさんは渋谷から乗り換え回数は気にせず45分以内。
二人が集まれる駅はある？
```

**期待される動作**:
- `baseList: ["新宿", "渋谷"]`、`upperMinutes: [30, 45]`、`upperTransferCounts: [0, -1]` で範囲探索
- 新宿からは乗り換えなし30分以内、渋谷からは乗換回数を問わず45分以内という異なる条件で探索される

**ポイント**:
- 配列の同じ位置の要素同士が対応します（1番目の起点駅には1番目の条件が適用される）
- 「乗り換え回数は気にしない」は `0` ではなく `-1` で表します。`0` は「乗り換えなし」という別の条件になります

### 例19: 交通手段を絞り込み、結果件数を制限する

**:speech_balloon: プロンプトでの指示**:
```
東京駅から新幹線と特急を使わずに1時間以内で行ける駅を、近い順に100件教えて
```

**期待される動作**:
- `shinkansen: "false"`、`limitedExpress: "false"` で在来線のみに限定
- `limit: 100` で所要時間が短い駅から100件に絞り込み

**ポイント**:
- `limit` を指定すると、起点駅からの所要時間が短い駅から順に採用されます
- 所要時間の上限を大きくすると探索結果が数百〜数千件になることがあります。一覧の網羅性が不要な場合は `limit` の指定で応答サイズを抑えられます

## 住所からの周辺駅検索

### 例20: 住所から最寄り駅を検索

**:speech_balloon: プロンプトでの指示**:
```
東京都杉並区高円寺北2丁目の最寄り駅を教えて
```

**期待される動作**:
- `address: "東京都杉並区高円寺北2丁目"` を指定して周辺駅検索
- `radius` 省略のため、`Point` は配列ではなく単一オブジェクトとして最寄りの1件（駅コード、座標、住所からの距離など）が返される

**ポイント**:
- `types` を指定しない場合、鉄道駅に限らずバス停等が最寄りとして返ることがあります（下記例では鉄道駅ではなくバス停が最寄りです）

**サンプルレスポンス（抜粋）**:

```json
{
  "ResultSet": {
    "Point": {
      "Station": {
        "code": "45643",
        "Name": "高円寺中学校／関東バス",
        "Type": { "text": "bus", "detail": "local" },
        "Yomi": "こうえんじちゅうがっこう"
      },
      "Prefecture": { "code": "13", "Name": "東京都" },
      "GeoPoint": {
        "longi": "139.39.15.77",
        "lati": "35.42.24.80",
        "longi_d": "139.654381",
        "gcs": "wgs84",
        "lati_d": "35.706889"
      },
      "Distance": "201"
    },
    "Base": {
      "Point": { "Name": "東京都杉並区高円寺北２丁目" }
    }
  }
}
```

### 例21: 検索半径を指定して周辺の駅を複数取得

**:speech_balloon: プロンプトでの指示**:
```
大阪府大阪市北区梅田から半径1kmにある駅をすべて教えて
```

**期待される動作**:
- `address: "大阪府大阪市北区梅田"`, `radius: 1000`, `stationCount: 0` を指定して周辺駅検索
- 半径1km以内の駅・バス停一覧が返される

**ポイント**:
- `radius` を指定すると `stationCount`（デフォルト10件）の範囲で複数の駅が返されます
- `stationCount` を`0`に指定すると検索結果全件を返します
- 交通種別を絞りたい場合は `types` を指定します（例: `["train"]` で鉄道駅のみ）

## ビジネスユースケース

### ユースケース1: 経費精算での交通費計算

**シナリオ**: 出張先への交通費を確認したい

**:speech_balloon: プロンプトでの指示**:
```
本社（東京駅）から取引先（大阪駅）への往復の交通費を教えて。最も安い経路でお願いします。
```

**期待される動作**:
1. 東京→大阪 の最安経路を探索（`sort: "price"`）
2. 往復の料金を計算

- 承認者が経路の妥当性を確認

## Tips

### 駅名の指定方法

駅名が曖昧な場合でも、AI エージェントが適切に解釈します:

```
しんじゅくから池袋
→ AI が「新宿」「池袋」と認識して探索
```

### 座標情報の活用

駅ではない地点を指定する場合は座標を使用:

```
この座標から東京駅への経路を教えて: 35.40.41.1,139.46.12.9,tokyo,20
→ 座標情報が経路探索に利用される
```

**注意**: 座標や住所の指定は「駅すぱあと API」の仕様に依存します。詳細は [「駅すぱあと API」ドキュメント](https://docs.ekispert.com/v1/api/search/course/extreme.html) を参照してください。

### 平均待ち時間探索の特性について

- **時刻指定は不可**: 具体的な出発時刻や到着時刻を指定した探索はできません
- **平均的な所要時間**: 実際のダイヤではなく、平均的な待ち時間を考慮した探索結果が返されます

### エラー時の対処

存在しない駅名や無効なパラメータを指定した場合、エラーメッセージが返されます:

```
存在しない駅を指定した場合:
→ {"status":400,"message":"駅が見つかりません。(xxxx)"}
→ AI エージェントが近い駅名を提案することもある
```
