## 駅情報の取得

### 例1: 駅名から駅情報を取得

**:speech_balloon: プロンプトでの指示**:
```
東京駅の情報を教えて
```

**期待される動作**:
- 「駅すぱあと API」が駅名「東京」で検索
- 東京駅の駅コードなどの情報が返される

**サンプルレスポンス（抜粋）**:

```json
{
  "ResultSet": {
    "Point": [
      {
        "Station": {
          "Name": "東京",
          "Code": "22828",
          "Prefecture": { "Name": "東京都" }
        }
      }
    ]
  }
}
```
**返される情報の例**:
- 駅名: 東京
- 駅コード: 22828
- 都道府県: 東京

### 例2: 駅コードから駅情報を取得

**:speech_balloon: プロンプトでの指示**:
```
駅コード 22741 の駅の情報を教えて
```

**期待される動作**:
- 「駅すぱあと API」が駅コード 22741（新宿駅）の情報を検索
- 新宿駅の詳細情報が返される

### 例3: 特定の交通種別の駅情報を取得

**:speech_balloon: プロンプトでの指示**:
```
高円寺駅のバス停の情報を教えて（路線バスだけ）
```

**期待される動作**:
- `type: "bus.local"` を指定して高円寺駅のバス停情報を取得
- バス停一覧が返される

### 例4: 駅の座標情報を取得

**:speech_balloon: プロンプトでの指示**:
```
東京駅の座標を教えて
```

**期待される動作**:
- 「駅すぱあと API」が駅名「東京」で検索
- 東京駅の駅コード、座標などの情報が返される

**サンプルレスポンス（抜粋）**:

```json
{
  "ResultSet": {
    "Point": [
      {
        "Station": {
          "Name": "東京",
          "Code": "22828",
          "Prefecture": { "Name": "東京都" },
          "GeoPoint": { "lati": "35.40.41.10", "longi": "139.46.13.60" }
        }
      }
    ]
  }
}
```
**返される情報の例**:
- 駅名: 東京
- 駅コード: 22828
- 座標: 北緯 35.40.41.10、東経 139.46.13.60
- 都道府県: 東京

## 基本的な経路探索

### 例5: シンプルな2地点間の経路探索

**:speech_balloon: プロンプトでの指示**:
```
東京駅から新宿駅への経路を教えて
```

**期待される動作**:
- 出発駅: 東京、目的駅: 新宿 で経路探索
- 駅すぱあと探索順（デフォルト）で複数の経路が返される

**返される情報の例**:
- 経路1: ＪＲ中央線快速（直通）
  - 所要時間: 約14分
  - 料金: 210円
  - 乗換回数: 0回
- 経路2: ＪＲ山手線内回り＋ＪＲ総武線
  - 所要時間: 約22分
  - 料金: 210円
  - 乗換回数: 1回

**サンプルレスポンス（抜粋）**:

```json
{
  "ResultSet": {
    "Course": [
      {
        "Price": [{ "Oneway": 120 }],
        "Route": {
          "timeOnBoard": "14",
          "transferCount": "0",
          "Line": [
            {
              "timeOnBoard": "14",
              "Name": "ＪＲ中央線快速"
            }
          ]
        }
      }
    ]
  }
}
```

### 例6: 料金が最も安い経路を探索

**:speech_balloon: プロンプトでの指示**:
```
東京駅から新宿駅への最も安い経路を教えて
```

**期待される動作**:
- `sort: "price"` を指定して経路探索
- 料金順にソートされた経路が返される

### 例7: 経由駅を指定した経路探索

**:speech_balloon: プロンプトでの指示**:
```
東京から大阪まで、名古屋経由で移動する経路を教えて
```

**期待される動作**:
- `viaList: "東京:名古屋:大阪"` で経路探索
- 東京→名古屋→大阪 の経路が返される

**返される情報の例**:
- 経路: 東京→(新幹線のぞみ)→新大阪→(ＪＲ東海道・山陽本線)→大阪
- 所要時間: 約2時間36分
- 料金: 8,910円(運賃)＋4,960円(自由席特急券)＝13,870円
- 乗換回数: 1回

## 詳細な条件を指定した経路探索

### 例8: 定期券の料金を確認

**:speech_balloon: プロンプトでの指示**:
```
東京から新宿までの3ヶ月定期券の料金を教えて
```

**期待される動作**:
- `sort: "teiki3"` を指定して経路探索
- 3ヶ月定期券の料金情報が含まれた経路が返される

**返される情報の例**:
- 経路: ＪＲ 中央線快速（東京→新宿）
- 1ヶ月定期: 8,820円
- 3ヶ月定期: 25,160円
- 6ヶ月定期: 47,660円

**注意**: 現在は、定期券の料金情報の取得のみ可能です。定期控除計算は今後のバージョンで対応予定です。

### 例9: 複数の回答を取得

**:speech_balloon: プロンプトでの指示**:
```
東京から大阪まで、10通りの経路を教えて
```

**期待される動作**:
- `answerCount: 10` を指定
- 最大10通りの経路が返される

**注意**:
- 実際の経路数は探索結果に依存するため、10通り未満になることもあります
- より多くの結果を得たい場合は `searchCount` を増やします

### 例10: 駅を確定させてから経路探索

**:speech_balloon: プロンプトでの指示**:
```
高円寺から野方二丁目までの関東バスの経路を教えて
```

**期待される動作**:
- `name: 高円寺` および `type: "bus"` を指定して駅情報取得
- `name: 野方二丁目` および `type: "bus"` を指定して駅情報取得
- 取得した駅情報を使用した `viaList: 高円寺駅北口／関東バス:野方二丁目／関東バス` を指定して経路探索
- 関東バス路線を含む経路が返される

**返される情報の例**:
- 経路: 高円寺駅北口／関東バス→(関東バス・高60系統)→野方二丁目／関東バス
- 所要時間: 5分
- 運賃: 230円
- 乗換回数: 0回

### 例11: 詳細な探索条件を指定（新幹線、飛行機利用なし、ICカード優先）

**:speech_balloon: プロンプトでの指示**:
```
新幹線や飛行機を使わずに、ICカード優先で東京から大阪へ行きたい
```

**期待される動作**:
- `shinkansen: "never"`, `plane: "never"`, `ticketSystemType: "ic"`, `preferredTicketOrder: "ic"`を指定して [探索条件生成](https://docs.ekispert.com/v1/api/toolbox/course/condition.html) を行う
- `viaList: "東京:大阪"` 、および、生成された探索条件 `conditionDetail: "T11212332323191:F332112112200010:A23121141:"` を指定して経路探索
- 新幹線を利用しない経路が返される

**返される情報の例**:
- 経路: 東京→(ＪＲ山手線外回り)→渋谷→(徒歩)→渋谷マークシティ(高速・連絡バス)→高速バス(新宿・渋谷－京都・枚方)→山科駅前(高速・連絡バス)→(徒歩)→山科→(ＪＲ東海道・山陽本線新快速)→大阪
- 所要時間: 7時間54分
- 運賃: 7,848円(IC)
- 乗換回数: 2回

### 例12: 出発時刻を指定した経路探索（ダイヤ探索）

**自然言語での指示**:
```
東京から新宿まで、明日の朝9時に出発する経路を教えて
```

**期待される動作**:
- `date: {{YYYYMMDD 形式の翌日の日付(数値)}}`, `time: "0900"`, `searchType: "departure"` を指定して経路探索
- 指定した出発時刻に基づく実際の列車の時刻表を使用した経路が返される

**返される情報の例**:
- 経路: 東京 9:00発→(ＪＲ中央線快速)→新宿 9:14着
- 所要時間: 14分
- 料金: 210円
- 乗換回数: 0回

**ポイント**:
- `searchType: "departure"` を指定することで、発時刻探索（早く到着し遅く出発する経路）が優先されます
- 時刻表に基づいた正確な出発時刻・到着時刻が取得できます

### 例13: 到着時刻を指定した経路探索（ダイヤ探索）

**自然言語での指示**:
```
東京から新宿まで、18時までに到着する経路を教えて
```

**期待される動作**:
- `time: "1800"`, `searchType: "arrival"` を指定して経路探索
- 18時までに到着する経路のうち、遅く出発し早く到着する経路が優先される

**返される情報の例**:
- 経路: 東京 17:46発→(ＪＲ中央線快速)→新宿 18:00着
- 所要時間: 14分
- 料金: 210円
- 乗換回数: 0回

**ポイント**:
- `searchType: "arrival"` を指定することで、着時刻探索（遅く出発し早く到着する経路）が優先されます
- できるだけ遅い時間に出発できる経路を検索できます

### 例14: 終電・始発の経路探索（ダイヤ探索）

**自然言語での指示（終電）**:
```
東京から大阪までの終電を教えて
```

**期待される動作**:
- `searchType: "lastTrain"` を指定して経路探索
- 指定日の最終ダイヤの経路が返される

**自然言語での指示（始発）**:
```
東京から大阪までの始発を教えて
```

**期待される動作**:
- `searchType: "firstTrain"` を指定して経路探索
- 指定日の始発ダイヤの経路が返される

**ポイント**:
- `lastTrain` と `firstTrain` では `time` パラメータは指定できません
- 終電・始発は日付によって変わる可能性があるため、`date` パラメータで日付を指定することを推奨します

### 例15: 複数の並び順で経路を比較（ダイヤ探索）

**自然言語での指示**:
```
横浜から池袋まで、18時までに到着する経路で、早い・安い経路をそれぞれ教えて
```

**期待される動作**:
- `time: "1800"`, `searchType: "arrival"`, `sort: "time"` を指定して時間順で経路探索
- `time: "1800"`, `searchType: "arrival"`, `sort: "price"` を指定して料金順で経路探索
- 両方の結果を比較して最適な経路を選択

**返される情報の例（早さ重視）**:
- 経路: 横浜 17:19発→(ＪＲ湘南新宿ライン快速)→池袋 17:57着
- 所要時間: 38分
- 料金: 660円
- 乗換回数: 0回

**返される情報の例（安さ重視）**:
- 経路: 横浜 17:07発→(東急東横線通勤特急)→渋谷→(ＪＲ湘南新宿ライン快速)→池袋 17:57着
- 所要時間: 50分
- 料金: 490円
- 乗換回数: 1回

**ポイント**:
- 同じ到着時刻制限でも、並び順によって異なる経路が最適解として提示される
- 時間と料金のトレードオフを比較検討できる

## ビジネスユースケース

### ユースケース1: 経費精算での交通費計算

**シナリオ**: 出張先への交通費を確認したい

**:speech_balloon: プロンプトでの指示**:
```
本社（東京駅）から取引先（大阪駅）への往復の交通費を教えて。最も安い経路でお願いします。
```

**期待される動作**:
1. 東京→大阪 の最安経路を探索（`sort: "price"`）
2. 往復の料金を計算
3. 経路の詳細と合計金額が返される

**活用方法**:
- 経費精算システムに自動入力
- 承認者が経路の妥当性を確認

### ユースケース2: 経路の妥当性確認

**シナリオ**: 申請された経路が妥当かチェックしたい

**:speech_balloon: プロンプトでの指示**:
```
渋谷から品川まで、申請金額が500円なのですが、これは妥当ですか？
```

**期待される動作**:
1. 渋谷→品川 の経路を複数探索
2. 各経路の料金と申請金額を比較
3. AI エージェントが妥当性を判断

**活用方法**:
- 経理担当者が申請内容を効率的にチェック
- 不正請求や入力ミスを防止

### ユースケース3: 複数候補からの経路選択

**シナリオ**: 移動時間と料金のバランスを見て経路を選びたい

**:speech_balloon: プロンプトでの指示**:
```
東京から福岡まで、時間順と料金順でそれぞれ上位3つの経路を教えて
```

**期待される動作**:
1. 時間順（`sort: "time"`）で3つ取得
2. 料金順（`sort: "price"`）で3つ取得
3. 両方の結果を比較しやすい形式で提示

**活用方法**:
- 出張計画の最適化
- 予算と時間の制約に応じた経路選択

### ユースケース4: バス経路の確認

**シナリオ**: 鉄道だけでなくバスも含めた経路を確認したい

**:speech_balloon: プロンプトでの指示**:
```
中野駅から練馬駅へ、関東バスで移動する経路を教えて
```

**期待される動作**:
1. 駅情報取得時に `type: "bus.local"` を指定
2. バス路線を含む経路が探索される
3. バス停名、路線名、料金などが返される

**活用方法**:
- 鉄道以外の交通手段も含めた経費精算
- 最寄り駅からのバス移動の確認

### ユースケース5: 出張規定に準拠した経路検索

**シナリオ**: 会社の規定で「新幹線のぞみ利用不可」「特急券は自由席」と決まっているため、その条件で経路を検索したい

**:speech_balloon: プロンプトでの指示**:
```
東京から新大阪まで、会社の規定（のぞみ利用不可、自由席利用）に合わせて経路を教えて
```

**期待される動作**:
1. `shinkansenNozomi: "never"`, `surchargeKind: "free"` を指定して探索条件生成
2. 生成した探索条件を使用して経路探索
3. 規定に準拠した経路（例: 新幹線ひかり・自由席利用）が返される

**活用方法**:
- 社内規定に違反しない経路の自動提案
- 出張申請時のチェック工数削減

## Tips

### 駅名の指定方法

駅名が曖昧な場合でも、AI エージェントが適切に解釈します:

```
しんじゅくから池袋
→ AI が「新宿」「池袋」と認識して探索
```

### 座標情報の活用

駅ではない地点を指定する場合は座標を使用:

```
この座標から東京駅への経路を教えて: 35.40.41.1,139.46.12.9,tokyo,20
→ 座標情報が経路探索に利用される
```

**注意**: 座標や住所の指定は「駅すぱあと API」の仕様に依存します。詳細は [「駅すぱあと API」ドキュメント](https://docs.ekispert.com/v1/api/search/course/extreme.html) を参照してください。

### 平均待ち時間探索の特性について

- **時刻指定は不可**: 具体的な出発時刻や到着時刻を指定した探索はできません
- **平均的な所要時間**: 実際のダイヤではなく、平均的な待ち時間を考慮した探索結果が返されます

### エラー時の対処

存在しない駅名や無効なパラメータを指定した場合、エラーメッセージが返されます:

```
存在しない駅を指定した場合:
→ {"status":400,"message":"駅が見つかりません。(xxxx)"}
→ AI エージェントが近い駅名を提案することもある
```
