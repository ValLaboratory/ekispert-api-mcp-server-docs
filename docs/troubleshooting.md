## 認証関連

### アクセスキーのエラー

**症状**:
- 「認証エラー」「Invalid access key」などのメッセージが表示される
- 駅すぱあと APIからエラーレスポンスが返される

**原因と解決方法**:

#### 1. アクセスキーが未設定または間違っている

**確認方法**:
- `mcp.json`（VS Code の場合は `.vscode/mcp.json`）の `ekispert-api-access-key` の値を確認
- 環境変数 `${env:EKISPERT_API_ACCESS_KEY}` を使用している場合、環境変数が正しく設定されているか確認

**解決方法**:
- 正しいアクセスキーを設定する
- 環境変数を利用している場合は、ターミナル等で `echo $EKISPERT_API_ACCESS_KEY` (macOS/Linux) や `$env:EKISPERT_API_ACCESS_KEY` (Windows) を実行し、値が表示されるか確認する
- **重要**: 環境変数を設定した後、VS Code を完全に再起動しないと反映されない場合があります。一度 VS Code を終了し、再度起動して試してください。
- アクセスキーの前後にスペースや改行が入っていないか確認する

#### 2. アクセスキーで利用できない機能を呼び出している

**確認方法**:
- ご契約内容をご確認の上、弊社営業担当まで[お問い合わせ](https://api-info.ekispert.com/form/inquiry/)ください

**解決方法**:
- ご契約プランを変更する

## 経路探索関連

### 駅が見つからない

**症状**:
- 「駅が見つかりません」などのエラーメッセージ
- 空のレスポンスが返される

**原因と解決方法**:

#### 1. 駅名の表記が正しくない

**確認方法**:
- 駅名の表記を確認（例: 「新宿」「しんじゅく」「SHINJUKU」など）

**解決方法**:
- 正式な駅名で指定する
- 読み仮名（ひらがな）で指定してみる
- AI エージェントに「〜という駅を検索して」と自然言語で依頼する

#### 2. 交通種別の指定が間違っている

**確認方法**:
- `type` パラメータが正しいか確認（例: バス停を探す場合は `type: "bus"`）

**解決方法**:
- 適切な `type` を指定する
- `type` を省略してすべての交通種別で検索する

#### 3. 駅すぱあと APIのデータに含まれていない

**確認方法**:
- [駅すぱあと API ドキュメント](https://docs.ekispert.com/v1/) で対応範囲を確認

**解決方法**:
- 最寄りの主要駅を代わりに使用
- 駅すぱあと APIのサポートに問い合わせ

### 期待した経路が返ってこない

**症状**:
- 探索結果が少ない
- 最適でない経路が表示される

**原因と解決方法**:

#### 1. ソート条件が期待と異なる

**確認方法**:
- どのソート順で結果を取得したいか確認（料金順、時間順など）

**解決方法**:
- AI エージェントに「最も安い経路」「最も早い経路」など明確に指示する
- または、`sort` パラメータを明示的に指定する

#### 2. 回答数が少ない

**確認方法**:
- `answerCount` のデフォルト値は 5

**解決方法**:
- AI エージェントに「10通りの経路を教えて」など回答数を指定する
- `answerCount` と `searchCount` を増やす（最大20）

#### 3. 探索条件が厳しすぎる

**確認方法**:
- 経由駅を多く指定しすぎていないか
- 日付や交通種別の条件が厳しすぎないか

**解決方法**:
- 条件を緩和してみる
- 経由駅を減らす

### パラメータのエラー

**症状**:
- 「Error: 'name' と 'code' は同時に指定できません。」などのエラー
- 「Error: 出発駅と到着駅を指定してください。」などのエラー

**原因と解決方法**:

#### 1. 駅情報取得で name と code を同時指定

**解決方法**:
- どちらか一方のみを指定する
- または、両方とも省略して検索する（大量の結果が返される可能性があります）
- AI エージェントに自然言語で依頼する（AI が適切なパラメータを選択）

#### 2. viaList が未指定

**解決方法**:
- 出発駅と目的駅を必ず指定する
- AI エージェントに「〜から〜への経路」と明確に指示する

#### 3. 日付の形式が不正

**確認方法**:
- `date` は YYYYMMDD 形式（例: 20251215）

**解決方法**:
- 正しい形式で指定する
- AI エージェントに「12月15日の経路」と自然言語で指定する（AI が変換）

## パフォーマンス関連

### レスポンスが遅い

**症状**:
- API のレスポンスに時間がかかる
- タイムアウトが発生する

**原因と解決方法**:

#### 1. ネットワーク接続が遅い

**確認方法**:
- インターネット接続速度を確認
- 駅すぱあと APIへの接続をテスト

**解決方法**:
- ネットワーク環境を改善
- Wi-Fi や有線接続を使用

#### 2. 探索条件が複雑

**確認方法**:
- `searchCount` が大きすぎないか
- 経由駅が多すぎないか

**解決方法**:
- 探索条件を簡素化
- `answerCount` と `searchCount` を減らす

## その他

### 設定ファイルが読み込まれない

**症状**:
- `mcp.json` の設定が反映されない

**原因と解決方法**:

#### 1. JSON の構文エラー

**確認方法**:
- JSON の形式が正しいか確認（カンマ、括弧、クォートなど）
- VS Code でファイルを開くと構文エラーが表示される

**解決方法**:
- JSON の構文を修正

#### 2. ファイルパスが間違っている

**確認方法**:
- VS Code をご利用の場合: `.vscode/mcp.json` が正しい場所にあるか確認
- その他の MCPクライアントの場合: クライアントのドキュメントで設定ファイルの配置場所を確認

**解決方法**:
- VS Code の場合: リポジトリのルートディレクトリに `.vscode/` フォルダがあることを確認
- 必要に応じてファイルを作り直す

#### 3. MCPクライアントを再起動していない

**解決方法**:
- VS Code や Claude Desktop などのMCPクライアントを再起動

## FAQ（よくある質問）

### Q1: XML 形式でレスポンスを取得できますか？

**A**: はい、可能です。`mcp.json`（VS Code の場合は `.vscode/mcp.json`）に以下を追加してください:

```json
"headers": {
  "ekispert-api-access-key": "${env:EKISPERT_API_ACCESS_KEY}",
  "ekispert-api-response-format": "xml"
}
```

### Q2: ダイヤ探索には対応していますか？

**A**: 現在は、平均探索（`searchType: "plain"`）のみ対応しています。今後のアップデートで、ダイヤ探索（時刻表ベースの探索）にも対応予定です。

### Q3: 定期券の控除計算はできますか？

**A**: 現在は、[経路探索（ `ekispert_api_search_routes` ）](./features.md#経路探索)のToolのレスポンスで、定期券の料金情報を取得することはできます。定期控除の計算機能については、今後のアップデートで対応予定です。

### Q4: 座標や住所から経路探索できますか?

**A**: はい、`viaList` パラメータで座標情報を指定できます。詳細は [利用可能な機能一覧](./features.md) を参照してください。住所情報については、駅すぱあと APIの仕様に従って利用可能です。
